# Submission checklist

- [ ] Run `npm install`
- [ ] Run `npm run build` and confirm it succeeds
- [ ] Run `npm run dev` and inspect Dashboard
- [ ] Click Attack Paths and select a path
- [ ] Test search and severity filter
- [ ] Check desktop and narrow-window layouts
- [ ] Push the full folder to GitHub
- [ ] Share the GitHub repository URL with the reviewer
- [ ] Mention that the project is an original concept using fictional data
